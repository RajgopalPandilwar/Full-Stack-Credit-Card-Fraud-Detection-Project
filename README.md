# Full Stack Credit Card Fraud Detection
Machine Learning system for detecting fraudulent credit card transactions.

**Author:** Rajgopal Pandilwar

## Youtube Video : https://youtu.be/oXxX0bfVgq8


### Tech Used :

| Layer | Technology |
|-------|-----------|
| Front End | HTML & CSS |
| Back End | Python (Flask) |
| Model | Jupyter Notebook (scikit-learn) |
| Database | CSV |

### Project Overview

This project demonstrates a complete fraud detection pipeline:
- Handles highly undersampled transaction data
- Uses KMeans SMOTE for data balancing
- Trains a Random Forest classifier for fraud prediction
- Achieves 99.9% accuracy on test data

### How to Run

1. Clone the repository
2. Install dependencies: `pip install flask pandas scikit-learn`
3. Train the model: open `credit-card-fraud-detection.ipynb` in Jupyter and run all cells
4. Run the app: `python app.py`
5. Open `http://localhost:5000` in your browser
